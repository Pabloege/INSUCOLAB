# 💻 INSUCOLAB

Sistema web para la consulta y organización de los laboratorios computacionales del Liceo Insuco de Valparaíso.

## 🌐 Sitio web

🔗 [Visitar INSUCOLAB](https://pabloege.github.io/INSUCOLAB/)

## 📋 Descripción

INSUCOLAB es un proyecto web desarrollado para facilitar la consulta de información relacionada con los laboratorios computacionales de la institución.

El sitio permite visualizar información de los laboratorios, sus sistemas operativos, cantidad de computadores, memoria RAM, estado y fotografías.

## 🎯 Objetivo

Crear una plataforma web clara, ordenada y accesible que permita consultar la información disponible de los laboratorios computacionales.

## ⚙️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

## ✨ Funcionalidades

- 🏫 Información general de la institución
- 💻 Consulta de laboratorios
- 🔎 Búsqueda y filtrado de laboratorios
- 🖼️ Galería de fotografías
- 📱 Diseño adaptable a dispositivos móviles
- ⚠️ Identificación de laboratorios fuera de servicio
- 🌐 Publicación mediante GitHub Pages
